
# 单步落脚轨迹规划任务说明

## 1. 本阶段范围

本阶段实现可指定物理端和目标附着面的单步运动：

* 任意一个物理磁吸端可作为固定支撑端；
* 另一个物理磁吸端可作为移动端；
* 选择一个附着面和一个物理磁吸端作为初始支撑；
* 规划到显式指定目标表面上可执行的候选附着点；
* `base_end`和`l8_end`均可作为支撑端或移动端；
* 暂不实现连续多步爬行和全局路径搜索。

## 2. 数据来源

### 机器人

从 `robots_model/` 中读取：

* URDF；
* meshes；
* `config/suction_frames.yaml`。

不得在规划代码中重复硬编码吸盘中心和法向。

### 铁塔和附着区域

从 `models/` 中读取：

* 铁塔碰撞或可视化模型；
* 附着面模型；
* 从candidiate_output文件夹中读取候选点 CSV 或 NPZ；
* 候选点坐标及文件中实际存在的其他字段。

实施前必须检查并报告：

1. CSV和NPZ分别有哪些字段；
2. 坐标单位；
3. 坐标表达在哪个坐标系；
4. 两份候选点文件分别对应哪个附着表面；
5. 文件中是否包含表面法向。

若数据文件中没有明确提供法向，不得擅自假设，应检查附着面STL是否可以提供对应三角面的法向，并在实施说明中明确采用的方法。

## 3. 初始状态

第一版自行选定以下参数：

* 支撑端候选点；
* 移动端目标候选点；
* 初始关节角，默认可先使用URDF零位；
* 轨迹插值步数；
* 碰撞安全距离。

程序应根据支撑吸盘的局部功能坐标系和支撑点目标位姿，计算整台机器人初始世界位姿，使 `base_link`吸盘准确落在指定支撑点上。

支撑吸盘应保持固定，不得仅依靠视觉上接近目标点。

## 4. 附着姿态

每个候选目标应形成完整的吸盘目标位姿，而非只有三维位置。

约定：

* 吸盘Z轴为吸盘法向；
* 吸盘法向朝向铁塔附着表面；
* 若铁塔表面法向朝外，则吸盘法向应与其反向对齐；
* 面内Y轴优先由吸盘局部坐标系定义的参考方向在目标表面切平面上的投影确定；
* X轴按右手坐标系计算；
* `base_end`和`l8_end`与`surface1`、`surface2`完全解耦；任意物理磁吸端均可尝试任意表面，最终受法向、关节限位、碰撞、同面吸盘间距和轨迹约束限制。

程序必须验证目标法向方向，避免吸盘朝向铁塔外侧。

## 5. IK目标转换

PyBullet逆运动学控制的是 `L8` link坐标系，而实际目标是定义在 `L8`上的吸盘功能坐标系。

必须使用坐标变换：

`世界到L8目标位姿 = 世界到吸盘目标位姿 × L8到吸盘局部变换的逆`

不得直接把吸盘中心目标位姿作为 `L8` link原点目标位姿。

## 6. 规划方法

第一版采用简单、可验证的方法：

1. 读取当前关节状态；
2. 对指定目标附着位姿求逆运动学；
3. 验证IK终点的位置误差和法向误差；
4. 在起始关节状态和目标关节状态之间做关节空间插值；
5. 对每个插值状态检查关节限位、自碰撞和机器人—铁塔碰撞；
6. 全部状态有效时，认为该单步轨迹成功；
7. 若直线插值失败，先明确报告失败位置和碰撞对象，本阶段不自动引入复杂规划器。

当前正式实现保留关节空间直线轨迹，并在直线失败时使用RRT-Connect兜底。

## 7. 碰撞逻辑

至少检查：

* 机器人各link与铁塔的碰撞；
* 机器人自碰撞；
* 移动过程中吸盘、机械臂和主体与非目标结构的碰撞。

应排除或单独处理合理接触：

* 固定支撑吸盘与其附着面的接触；
* 轨迹终点移动吸盘与目标附着面的接触。

不能因为支撑吸盘正常接触铁塔，就把所有轨迹都判为碰撞。

## 8. 验证指标

至少输出：

* 初始支撑点编号和坐标；
* 目标点编号和坐标；
* IK是否成功；
* 末端吸盘位置误差；
* 吸盘法向角度误差；
* 各关节目标角；
* 是否违反关节限位；
* 轨迹第几步发生碰撞；
* 碰撞涉及的机器人link和铁塔对象；
* 最终规划成功或失败。

推荐初始阈值：

* 位置误差：不超过5 mm；
* 法向误差：不超过3°；
* 轨迹插值：至少50个状态。

这些阈值应集中配置，避免散落在代码中。

## 9. PyBullet可视化

GUI中显示：

* 铁塔；
* 机器人；
* 初始支撑点；
* 移动端目标点；
* 两个吸盘功能坐标系；
* 候选目标位姿坐标系；
* 规划成功时按顺序播放轨迹。

坐标轴颜色统一为：

* X轴红色；
* Y轴绿色；
* Z轴蓝色。

## 10. 代码组织

实施前先检查现有 `pyproject.toml` 和项目结构，再决定模块位置。

优先目标是形成：

* 一个可复用的吸盘配置读取模块；
* 一个坐标变换模块；
* 一个候选点读取模块；
* 一个单步规划模块；
* 一个可直接运行的演示入口。

不得修改 `legacy_scripts/` 中的文件。

## 11. 完成标准

本阶段完成时应能够用一条明确命令：

1. 加载机器人和铁塔；
2. 固定指定物理磁吸端；
3. 求解指定运动端吸盘的目标姿态；
4. 生成并验证一条关节空间轨迹；
5. 在GUI中播放成功轨迹，或明确输出失败原因。
